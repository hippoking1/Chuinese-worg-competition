# 字音字型小達人 (國小組全國語文競賽模擬測驗 PWA)

專為平板／手機觸控筆手寫設計之國語文競賽字音字形模擬測驗 Web App。已完整收錄 113 與 114 年度國小學生組共 400 題完整字音字形試題與標準解答，支援 GitHub Pages 一鍵部署與 Google 試算表雲端整合。

---

## 🌟 核心特色

1. **競賽規格模擬**：
   - **正式模擬測驗**：字音 100 題 ＋ 字形 100 題，倒數計時 20 分鐘，每字 0.5 分（滿分 100 分），時間到自動交卷。
   - **每日迷你挑戰**：字音 25 題 ＋ 字形 25 題，限時 5 分鐘。
   - **自由練習模式**：10 / 20 / 50 題自選，即時看正解。
   - **歷屆試卷整卷**：114年 / 113年 字音、字形單科 100 題完整試卷。
   - **常錯字錯題本**：針對歷史錯題加權出題，連續答對 3 次才從錯題本移出。
2. **混合批改機制**：
   - 自動在背景初判對錯（字形使用 Google 手寫辨識、字音使用輕量 $P 點雲演算法與聲調方向判別）。
   - 交卷後提供清楚的直覺核對清單，左右對照小朋友筆跡與正楷標準答案，可點擊單鍵翻轉切換判定。
   - 支援筆順回放動畫（重播寫字過程），家長可檢視筆劃筆順。
3. **平板手寫體驗優化**：
   - 支援 Apple Pencil 與 S Pen 觸控筆防手掌誤觸（Palm Rejection）。
   - 120Hz/240Hz 觸控筆取樣與二次貝茲曲線平滑渲染，筆感順暢。
   - 考究的國語文競賽格式：字形題提供米字格；字音題提供「聲母、介母、韻母、聲調」專用競賽欄位。
   - 專屬「注音個人化校正」功能：小朋友親寫 37 個注音符號建立個人字跡特徵，大幅提升手寫辨識率。
4. **家庭多選手模式**：
   - 支援 1–3 位小朋友切換頭像與專屬 4 位數 PIN 碼，共用平板不混淆紀錄。
   - 家長管理專區，可檢視所有選手進度、設定 PIN 碼及自訂雲端題庫。
5. **雲端與離線雙軌**：
   - 支援 Google Sheets + Apps Script 雙向同步。
   - 支援 PWA 離線快取，沒網路照常練，重新連線後一鍵上傳暫存成績。

## 🚀 GitHub Pages 部署步驟

本專案已設定好自動化 GitHub Actions Workflow，只需以下簡單步驟：

1. **開啟 GitHub Pages 設定**：
   - 前往你的 GitHub 專案頁面：`https://github.com/hippoking1/Chuinese-worg-competition`
   - 點擊上方 **Settings** ➜ 左側欄位選 **Pages**。
   - 在 **Build and deployment** 下方的 **Source**，將其切換為 **GitHub Actions**。
2. **自動建置與發布**：
   - 程式碼 Push 至 `main` 分支後，GitHub Actions 即會自動執行驗證、建置並發布至 GitHub Pages。
   - 發布完成後的網頁網址通常為：`https://hippoking1.github.io/Chuinese-worg-competition/`
3. **在平板上安裝為 App (PWA)**：
   - **iPad (Safari)**：打開網址 ➜ 點擊分享按鈕 ➜ 選擇「**加入主畫面**」。
   - **Android 平板 (Chrome)**：打開網址 ➜ 點擊右上角選單 ➜ 選擇「**安裝應用程式**」或「**加到主畫面**」。

## 📊 Google 試算表（成績與題庫）設定步驟

若希望將測驗成績同步到自己的 Google 雲端試算表：

1. 新增一份空白 Google 試算表（命名例如：`字音字形競賽成績總表`）。
2. 點擊頂部選單的 **擴充功能 ➜ Apps Script**。
3. 將本專案 `apps-script/Code.gs` 與 `apps-script/Setup.gs` 複製貼上到專案編輯器中。
4. 在上方函式下拉選單選擇 `setup`，點擊「執行」（首次執行需授權）。
   - `setup()` 會自動建立 5 個工作表：`Questions`、`Players`、`Attempts`、`Mastery`、`Config`，並在執行紀錄中顯示一組隨機產生的 `api_token`。
5. 點擊右上角 **部署 ➜ 新增部署作業**：
   - 種類選 **網頁應用程式**。
   - 說明填寫：`v1.0`。
   - **執行身分**：選「我」。
   - **誰可以存取**：選「**任何人** (Anyone)」。
   - 點擊部署後，複製得到的「**網頁應用程式網址 (URL)**」（結尾為 `/exec`）。
6. 回到本 App 的「家長管理專區」，貼上該網址與 `api_token` 點擊儲存，即可完成雲端串接！

## 📝 題庫擴充方法

未來若要新增歷屆試題或自訂練習題庫，有三種擴充途徑：

1. **直接在 Google 試算表新增**：
   - 在試算表的 `Questions` 分頁直接追加一列（填寫 id, type, context, target, char, zhuyin 等欄位）。
   - 編輯後 `onEdit` 會自動刷新題庫版本號，所有平板下次打開 App 便會自動下載最新題庫。
2. **修改本機題庫**：
   - 編輯 `data/questions.csv` 或 `public/questions.json`。
   - 執行 `npx tsx scripts/validate_questions.ts` 確認格式完全正確無誤。
3. **原卷校對工具**：
   - 開啟 `public/proof.html`，可隨時對照 113 與 114 年 400 題的原始掃描裁切圖進行核對。
